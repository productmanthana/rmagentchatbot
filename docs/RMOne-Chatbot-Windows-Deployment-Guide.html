1 Install NVM for Windows

NVM (Node Version Manager) allows you to install and switch between multiple Node.js versions.

  1. Open your browser and go to:
    https://github.com/coreybutler/nvm-windows/releases
  2. Scroll down to the latest release and download nvm-setup.exe
  3. Run the installer and accept all default settings
  4. Close and reopen PowerShell as Administrator
  5. Verify installation: 
    nvm version
    You should see the NVM version number (e.g., 1.1.12)

2 Install Node.js via NVM

Open Administrator PowerShell and run the following commands:

nvm install 20.18.0
nvm use 20.18.0

Verify the installation:

node -v
npm -v
Expected Output:
node -v should show v20.18.0
npm -v should show a version number (e.g., 10.8.2)

3 Install Git

If Git is not already installed on the server:

  1. Open your browser and go to:
    https://git-scm.com/download/win
  2. Download the Windows installer (64-bit)
  3. Run the installer and accept all default settings
  4. Close and reopen PowerShell
  5. Verify installation: 
    git --version
    You should see the Git version number

4 Clone the Repository

Open Administrator PowerShell and run:

cd C:\UGIT\RMOneAgent
git clone https://github.com/productmanthana/rmagentchatbot.git
cd rmagentchatbot
Note: If the folder C:\UGIT\RMOneAgent does not exist, create it first: 
mkdir C:\UGIT\RMOneAgent

5 Create the Environment File (.env)

Create a file named .env in the project root folder C:\UGIT\RMOneAgent\rmagentchatbot\.env

Open Notepad and add the following content (replace the placeholder values with your actual credentials):

APP_MSSQL_URL=your_app_database_connection_string
CLIENT_MSSQL_URL=your_client_database_connection_string
CLIENT_TABLE_NAME=your_table_name
OPENAI_API_KEY=your_openai_api_key
Important: Never share or commit the .env file. It contains sensitive credentials. When saving in Notepad, use "Save As", change file type to "All Files (*.*)", and name it .env (with the dot at the beginning).

6 Install Dependencies and Build

In Administrator PowerShell, navigate to the project folder and run:

cd C:\UGIT\RMOneAgent\rmagentchatbot
npm install
npm run build
Note: npm install downloads all required packages. npm run build compiles the frontend and backend code into the dist folder. This may take 1-2 minutes.

7 Test the Application (Manual Run)

Before setting up PM2, test that the application runs correctly:

cd C:\UGIT\RMOneAgent\rmagentchatbot
node dist/index.js
  1. Open your browser and go to http://localhost:5000
  2. Verify the chatbot loads correctly
  3. Once verified, press Ctrl+C in PowerShell to stop the application

8 Install PM2 Process Manager

PM2 keeps the application running in the background and automatically restarts it if it crashes or the server reboots.

In Administrator PowerShell, run:

npm install -g pm2
npm install -g pm2-windows-startup
pm2-startup install
What each command does:
- npm install -g pm2 - Installs PM2 globally
- npm install -g pm2-windows-startup - Enables PM2 to start automatically when Windows boots
- pm2-startup install - Registers PM2 as a Windows service

9 Start the Application with PM2

cd C:\UGIT\RMOneAgent\rmagentchatbot
pm2 start dist/index.js --name rmone-chatbot
pm2 save

Verify the application is running:

pm2 status
Expected Output: You should see rmone-chatbot with status online. The application is now accessible at http://localhost:5000.

10 Configure PM2 Log Rotation

Log rotation prevents log files from growing indefinitely and consuming disk space.

pm2 install pm2-logrotate
pm2 set pm2-logrotate:max_size 10M
pm2 set pm2-logrotate:retain 3
SettingValueDescription
max_size10MRotate logs when they reach 10 MB
retain3Keep only the last 3 log files

11 Create Update Batch File

Create this batch file to simplify future code updates. Save it as C:\UGIT\RMOneAgent\update-chatbot.bat

Open Notepad, paste the following content, and save as update-chatbot.bat (file type: All Files):

@echo off
echo ========================================
echo   RMOne Chatbot - Full Update
echo ========================================
echo.
cd /d C:\UGIT\RMOneAgent\rmagentchatbot
echo Stopping PM2...
call pm2 stop rmone-chatbot
echo.
echo Pulling latest code...
git pull
echo.
echo Installing dependencies...
call npm install
echo.
echo Building frontend...
call npm run build
echo.
echo Starting PM2...
call pm2 start rmone-chatbot
echo.
echo ========================================
echo   Update Complete!
echo ========================================
pause

How to Use the Update Batch File

  1. Navigate to C:\UGIT\RMOneAgent\
  2. Right-click on update-chatbot.bat
  3. Select "Run as administrator"
  4. Wait for it to complete
Important: Always right-click and select "Run as administrator". Running without admin privileges will cause permission errors.

13 Switching Node.js Versions

If you need to use a different Node.js version in the future, follow these steps in Administrator PowerShell:

nvm install 22.0.0
nvm use 22.0.0
node -v
Important: After switching Node.js versions, you must reinstall PM2 and rebuild the application: 
npm install -g pm2
npm install -g pm2-windows-startup
pm2-startup install

cd C:\UGIT\RMOneAgent\rmagentchatbot
npm install
npm run build

pm2 start dist/index.js --name rmone-chatbot
pm2 save

To see all installed Node.js versions:

nvm list

To switch back to a previously installed version:

nvm use 20.18.0

14 Troubleshooting

Problem: PM2 shows "connect EPERM" error

Cause: PowerShell is not running as Administrator, or PM2 daemon is stuck.

Solution:

pm2 kill
Remove-Item -Recurse -Force $env:USERPROFILE\.pm2
npm install -g pm2
cd C:\UGIT\RMOneAgent\rmagentchatbot
pm2 start dist/index.js --name rmone-chatbot
pm2 save

Problem: Build fails with "EPERM: operation not permitted, unlink"

Cause: PM2 is still running and has locked the files in the dist folder.

Solution:

pm2 stop rmone-chatbot
Remove-Item -Recurse -Force C:\UGIT\RMOneAgent\rmagentchatbot\dist
npm run build
pm2 start rmone-chatbot

Problem: "import.meta.dirname is not defined" error

Cause: You are using a Node.js version below 20.

Solution:

nvm use 20.18.0
node -v

Problem: Application not accessible after server reboot

Cause: PM2 auto-startup may not have been configured properly.

Solution:

npm install -g pm2-windows-startup
pm2-startup install
pm2 start dist/index.js --name rmone-chatbot
pm2 save

Problem: Git pull shows "Permission denied"

Cause: PowerShell is not running as Administrator.

Solution: Close PowerShell, right-click it, and select "Run as Administrator". Then try again.

Problem: Application shows errors in logs

How to check:

pm2 logs rmone-chatbot --lines 50
