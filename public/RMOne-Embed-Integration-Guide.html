1. Executive Summary

RMOne AI Agents provides a powerful one-click embed solution that allows external websites to integrate the AI-powered project query chatbot seamlessly. This document outlines the architecture, security model, and implementation approach for embedding the chatbot on client portals like rmone.com.

Key Benefits:
  • One-click embed generation with unique secure tokens
  • Domain-restricted access with automatic subdomain support
  • Role-based permissions (Superadmin, Admin, User)
  • Token-based authentication (works in all browsers, including Safari)
  • No cookies required - iframe compatible

2.1 Component Overview

  • Integration Management Page: Admin interface to create/manage embed links
  • Embed Token System: Secure 16-character unique identifiers per embed
  • Domain Validator: Restricts embed usage to authorized domains
  • Role-Based Access Control: Three permission levels with granular access
  • Session Management: Isolated chat history per embed instance

3. How It Works

1
Create Embed Link

Admin navigates to Integration page and creates a new embed link with name, role, and allowed domain.

2
Configure Domain

Specify the allowed domain (e.g., rmone.com). All subdomains are automatically included (e.g., portal.rmone.com, app.rmone.com).

3
Select Role

Choose permission level: Superadmin (full access), Admin (logs + FAQ), or User (chat only).

4
Copy & Embed

Copy the generated iframe code and paste into your website. That's it!

5. Security Features

Token-Based Authentication

Unlike traditional cookie-based auth, embed uses secure tokens sent via HTTP headers. This bypasses third-party cookie restrictions in modern browsers (Safari, Chrome) making it iframe-compatible.

  • Domain Validation: Embeds only work on authorized domains
  • Unique Tokens: Each embed has a cryptographically secure 16-character ID
  • Isolated Sessions: Each embed instance has separate chat history
  • No Cookie Dependency: Works reliably in all iframe scenarios
  • Audit Trail: Last-used timestamps tracked for each embed

6. Implementation Example

6.1 Basic Embed (Full Page)

<iframe src="https://rmchat.vyaasai.com/embed/[EMBED_ID]" width="100%" height="100%" frameborder="0" style="border: none;"> </iframe>

@if (User.IsInRole("Administrator")) { // Admin embed - shows logs and FAQ management <iframe src="https://rmchat.vyaasai.com/embed/ADMIN_EMBED_ID" width="100%" height="100%" frameborder="0"></iframe> } else { // User embed - chat only <iframe src="https://rmchat.vyaasai.com/embed/USER_EMBED_ID" width="100%" height="100%" frameborder="0"></iframe> }

7. Domain Configuration

Subdomain Support

When you set the allowed domain to rmone.com, the following are automatically allowed:

  • rmone.com (exact match)
  • portal.rmone.com (subdomain)
  • app.rmone.com (subdomain)
  • staging.portal.rmone.com (nested subdomain)

8. Quick Start Checklist

  1. Login to RMOne AI Agents as Superadmin
  2. Navigate to Integration page
  3. Click "Create New Embed Link"
  4. Enter a descriptive name (e.g., "RMOne Portal - Admin")
  5. Set the allowed domain (e.g., rmone.com)
  6. Select the appropriate role
  7. Click Create
  8. Copy the iframe code
  9. Paste into your website HTML
  10. Done! The chatbot is now embedded.
